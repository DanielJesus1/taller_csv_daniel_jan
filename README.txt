PAQUET DOCENT — CSV AMB ESQUEMES VARIATS

Cada CSV té 120 registres. Els noms dels camps varien segons el sector:
- 3 camps de classificació obligatoris
- 2 camps numèrics per fer càlculs i agregacions
- 1 camp de data

Els tipus d'incidència es mantenen iguals:
1. camps obligatoris buits o amb només espais;
2. valors numèrics que no es poden interpretar segons el tipus de camp, o que no són positius;
3. dates invàlides o amb format no admès;
4. espais sobrants i coma decimal vàlida que es pot normalitzar.

IMPORTANT: els CSV ja no són intercanviables directament amb el notebook original, perquè aquest espera els noms producte/categoria/ciutat/unitats/preu_unitari/data. Cal adaptar-hi els noms de camps, les funcions/conversions segons el tipus numèric i els indicadors del negoci de cada CSV. Les regles generals de qualitat es mantenen.
